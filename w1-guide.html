How to submit on Canvas
  1. Confirm all six files are in your primary repo at workshops/week-01/ and role-analyses/week-01/.
  2. In your terminal:
    git add workshops/week-01/ role-analyses/week-01/
    git commit -m "W1: system selection, sequencing plan, attack surface map (3 layers + verification), session log"
    git push
  3. On GitHub, open your primary repo and click the commit hash to open the commit page.
  4. Copy that URL (it looks like github.com/[username]/[repo]/commit/[hash]).
  5. On Canvas → Module 1 → Workshop 1, paste the commit URL and submit.
