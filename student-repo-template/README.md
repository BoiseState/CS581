# Student Repository Template

This folder contains the starting structure for both repositories you will create in Week 1.

**Do not submit work to this folder.** Copy the structure into your own repos.

---

## Two Repositories

CS 581 requires two separate GitHub repositories:

### Primary Repo — Technical Artifacts
Copy `primary-repo/` as the starting structure. This is where your workshop artifacts, session logs, and written assignments live. It is your technical portfolio.

### Secondary Repo — Role Analyses
Copy `secondary-repo/` as the starting structure. This is where your role analysis work lives — reading the same material through different organizational lenses each module.

---

## How to Use These Templates

1. **Week 1, Day 1:** Create both repos on GitHub — **make them private**
   - Suggested names: `cs581-primary` and `cs581-secondary`
   - Private repos prevent other students from reading your threat models and attack surface maps
2. Copy `primary-repo/` contents into your primary repo
3. Copy `secondary-repo/` contents into your secondary repo
4. **Add your instructor as a collaborator with Read access** on both repos:
   - Settings → Collaborators → Add people → search `cspirito` → role: Read
5. Submit both repo URLs via the Repository Setup assignment on Canvas (Module 1)
6. Fill in placeholder files as you complete each workshop — commit as you go, not all at once

---

## What the Placeholders Contain

Every artifact file has:
- The correct filename and header structure
- HTML comments (`<!-- like this -->`) explaining what goes in each section
- Section headings matching the rubric criteria

Every session log has the correct structure for logging AI sessions as they happen.

**See `example-student-work/week-01/`** in this repo for a complete W1 submission showing what filled-in versions look like.

---

## Commit Discipline

Grading is based on the last commit before the deadline. Commit meaningful progress regularly — not everything at once the night before. Your commit history is visible and is part of the professional artifact you are building.
